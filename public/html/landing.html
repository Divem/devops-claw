常见问题

关于 DevOps Claw 的内部常见问题解答

DevOps Claw 是什么？支持哪些 Agent 类型？+
DevOps Claw 是公司内部的 AI Agent 托管平台，支持 OpenClaw 和 Hermes Agent 两种类型的一键创建与部署。与通用的 Agent 托管平台不同，DevOps Claw 深度集成了公司现有的 DevOps 工具链（CI/CD、云测、可观测、质量中台等），让 AI Agent 不仅能对话，还能直接操作企业基础设施。
OpenClaw 和 Hermes Agent 有什么区别？+
OpenClaw 是轻量敏捷的开源 AI 助手框架，强调模型选择自由与数据自主，适合追求极简部署、灵活自定义和快速上手的团队，可一键接入飞书、Discord 等多平台。Hermes Agent 是具备持续进化能力的 24/7 自主代理，自动从经验中创建和优化技能，适合需要代理长期自主学习并处理复杂任务的企业场景。
如何创建自己的 AI Agent？+
登录平台后，在首页点击「创建 Agent」按钮，选择 Agent 类型（OpenClaw 或 Hermes），填写名称和基本配置即可。系统会自动完成 VM 分配、Agent 安装等底层操作，通常几分钟内就能完成。创建成功后，你可以通过 Gateway Dashboard 进行个性化配置和 DevOps 工具授权。
AI Agent 能操作哪些 DevOps 工具？+
目前 Agent 已集成魔方（CI）、云渡（CD）、云测平台、质量中台、后端可观测 FastX、前端可观测 ORS、洞察（研效度量）等核心 DevOps 工具。通过 Gateway Dashboard 可以为每个 Agent 配置具体的工具访问权限。同时提供 OpenAPI、MCP 和 CLI 开放能力，支持自定义插件扩展。
创建 AI Agent 需要管理员审批吗？+
实例创建本身是自动化的，不需要审批。但如果你想将 Agent 接入飞书对话，需要管理员审批飞书长连接申请。此外，管理员需要为 Agent 配置 DevOps 工具访问权限，这是为了确保工具调用的安全性和规范性。
我的对话数据安全吗？+
所有 AI Agent 实例运行在公司内网，对话数据全程在企业内部流转，不会经过外部网络。平台通过 IAM 统一认证，提供操作审计日志，关键操作都有记录可追溯。你可以放心在 Agent 中讨论工作相关的内容。
遇到问题应该找谁？+
如果是使用问题，可以在飞书群「DevOps Claw 交流群」中提问。如果是实例运行异常或功能 Bug，可以通过飞书机器人提交工单，DevOps 团队会尽快响应处理。
