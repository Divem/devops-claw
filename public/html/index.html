常见问题

关于 DevOps Claw 的常见问题解答

DevOps Claw 与原版 OpenClaw 有什么区别？ +
DevOps Claw 是原版 OpenClaw 的企业级部署方案，保留了 OpenClaw 的所有核心功能。在此基础上，我们提供了更简单的部署方式、更强大的管理控制台、更完善的企业级安全功能，以及专业的技术支持服务。
部署需要多长时间？ +
使用我们的一键部署工具，通常在 5 分钟内即可完成完整的环境搭建和实例启动。对于 Kubernetes 环境，我们也提供了 Helm Chart，可以快速集成到现有集群中。
支持哪些即时通讯平台？ +
目前我们支持飞书、钉钉、企业微信、Slack、Discord 等主流 IM 平台。我们会持续增加对更多平台的支持，您也可以基于我们的 SDK 开发自定义适配器。
如何确保数据安全？ +
DevOps Claw 采用私有化部署模式，所有数据存储在企业自有服务器上，不出企业内网。同时我们提供完整的权限控制、审计日志、传输加密等安全功能，并通过了多项国际安全认证。
是否支持自定义插件开发？ +
是的，我们提供完整的插件开发 SDK 和文档，支持使用 Python、JavaScript 等语言开发自定义插件。企业版用户还可以获得我们的插件开发支持和审核服务。
提供免费试用吗？ +
是的，我们提供 14 天的专业版免费试用，无需信用卡。试用期间您可以体验所有专业版功能，我们的技术团队也会协助您完成部署和配置。
