## Context

当前 OpenClaw 平台的配置页面提供了「控制台」和「代码模式」两种视图模式：
- **控制台**: 可视化的表单配置界面
- **代码模式**: JSON/YAML 格式的代码编辑器

用户需要一个第三种视图模式——终端视图，以模拟 Linux 终端的方式展示配置信息，增强技术感和专业度。

## Goals / Non-Goals

**Goals:**
- 在配置页面添加「终端」标签页，位于「代码模式」之后
- 实现类 Ubuntu 终端的视觉风格（深色背景、绿色文字、等宽字体）
- 显示系统欢迎信息、配置统计信息和命令行风格的配置内容
- 保持与现有标签切换行为一致
- 纯前端实现，无需后端 API 变更

**Non-Goals:**
- 不是真正的终端模拟器（不支持实际命令执行）
- 不引入重量级终端库（如 xterm.js），保持轻量
- 不支持交互式命令输入（纯展示）
- 不涉及现有控制台和代码模式的功能修改

## Decisions

### 1. 技术方案：纯 CSS 实现 vs 终端库
**选择**: 纯 CSS + Vue 组件实现
**理由**:
- 需求仅为静态展示，不需要真实终端功能
- 避免引入 xterm.js 等库的额外依赖和包体积
- 更容易自定义样式匹配设计需求
- 实现简单，维护成本低

**替代方案**: xterm.js
- 优点：功能完整，支持真实终端交互
- 缺点：过重，本需求不需要真实终端能力

### 2. 组件架构
```
ConfigPage
├── ConsoleTab (现有)
├── CodeModeTab (现有)
└── TerminalTab (新增)
    └── TerminalView
        ├── TerminalHeader (系统信息)
        └── TerminalContent (配置内容)
```

### 3. 样式方案
- **背景**: `#1e1e1e` (VS Code 终端深色)
- **文字颜色**: 
  - 普通文本: `#d4d4d4`
  - 绿色高亮: `#4ec9b0`
  - 蓝色链接: `#569cd6`
  - 黄色警告: `#dcdcaa`
- **字体**: `Monaco, Consolas, 'Courier New', monospace`
- **内边距**: `16px`
- **行高**: `1.5`

### 4. 内容渲染策略
- 使用 `<pre>` 标签保持格式
- 配置内容以 `cat config.yaml` 命令输出形式展示
- 添加模拟的命令提示符前缀

## Risks / Trade-offs

**[风险] 终端内容过长导致性能问题** → 使用虚拟滚动或分页展示（如超过 1000 行）

**[风险] 样式与系统主题不兼容** → 仅支持深色主题，不提供亮色主题切换

**[风险] 可访问性问题** → 确保颜色对比度符合 WCAG 标准（深色背景配浅色文字）

## Migration Plan

无需迁移，纯新功能：
1. 开发 TerminalTab 组件
2. 在配置页面添加新标签
3. 联调测试
4. 合并发布
