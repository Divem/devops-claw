## Why

管理端目前缺少实例管理页面，管理员无法统一查看和管理所有 OpenClaw 实例。需要提供一个管理端实例列表页，并配备创建实例的弹框（复用用户端的创建项目样式，但去掉用户选择步骤，由管理员直接创建实例）。

## What Changes

- 新增管理端「实例管理」页面，展示所有实例列表（状态、所属用户、创建时间等）
- 新增「创建实例」弹框，参考用户端创建项目的 UI 样式，但去掉用户选择字段
- 实例列表支持查看状态（运行中 / 停止 / 初始化中）、操作（启动、停止、删除）

## Capabilities

### New Capabilities
- `admin-instance-management`: 管理端实例管理页面，包含实例列表视图和创建实例弹框

### Modified Capabilities

## Impact

- 新增管理端路由 `/admin/instances`
- 复用用户端创建弹框的组件结构（表单布局、样式），适配为管理端场景
- 依赖 Mock 数据（MSW），无需真实后端
