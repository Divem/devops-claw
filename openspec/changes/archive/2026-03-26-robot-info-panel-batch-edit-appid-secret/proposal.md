## Why

当前机器人信息面板中，AppID 和 secret 需要逐个修改，操作流程繁琐。用户期望能够在一个界面中同时编辑并保存这两个关联配置，提升配置效率和用户体验。

## What Changes

- **机器人信息面板表单优化**：将 AppID 和 secret 的编辑模式从「单字段独立编辑」改为「批量编辑模式」
- **新增批量编辑功能**：支持在同一个表单中同时修改 AppID 和 secret
- **统一验证逻辑**：在保存时同时校验 AppID 和 secret 的有效性
- **原子性保存**：确保两个字段要么同时更新成功，要么都不更新，避免数据不一致

## Capabilities

### New Capabilities
- `robot-batch-edit-credentials`: 机器人凭证批量编辑能力，支持 AppID 和 secret 同时修改

### Modified Capabilities
<!-- 无现有能力需要修改 -->

## Impact

- **前端组件**：机器人信息面板表单组件
- **API 接口**：可能需要新增或修改保存凭证的接口以支持批量更新
- **用户界面**：表单交互方式变更，需要更新 UI 文案和提示
- **向后兼容**：此变更为功能增强，不影响现有 API 的向后兼容性
