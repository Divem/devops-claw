## Context

当前 OpenClawAdmin.vue 使用侧边导航中的按钮切换控制台/代码模式，代码模式下侧边导航折叠为 60px 窄条。参考飞书截图，应将模式切换改为顶部 Tab 栏。

## Goals / Non-Goals

**Goals:**
- 在管理页面顶部添加模式切换 Tab 栏（控制台 / 代码模式）
- Tab 栏左侧显示项目信息（返回按钮 + 头像 + 名称 + 状态），右侧显示模式切换 Tab
- 代码模式下完全隐藏侧边导航，内容区全宽展示
- 控制台模式下保持现有侧边导航 + 内容区布局

**Non-Goals:**
- 不修改 iframe 嵌入和 Gateway 代理逻辑
- 不修改骨架屏和错误处理逻辑

## Decisions

### 1. 顶部 Tab 栏结构

顶部栏分左右两区：
- **左侧**：返回按钮 + 项目头像 + 项目名称 + 状态标签
- **右侧**：「控制台」「代码模式」两个 Tab 切换 + 「去对话」按钮

### 2. 代码模式布局变化

代码模式下侧边导航通过 `v-if` 完全隐藏（而非折叠），内容区通过 flex 自动占满全宽。不再需要侧边导航折叠动画和 `.collapsed` 样式。

### 3. 模式切换状态

保留 `isCodeMode` ref 和 `setCodeMode()`/`setConsoleMode()` 方法，仅移除侧边折叠相关逻辑。

## Risks / Trade-offs

- **[Tab 栏高度占用]** → Tab 栏高度约 48px，相比侧边折叠方案略微减少内容区纵向空间，但换来更直观的切换体验
