## Context

当前对话界面存在以下问题：
1. 机器人名称显示为空，影响用户识别当前对话对象
2. "编辑凭证"按钮文案不够直观，用户不易理解其功能
3. 编辑机器人状态下缺少无机器人时的引导提示

这是一个纯前端 UI 层面的优化，涉及文案修改和链接跳转功能。

## Goals / Non-Goals

**Goals:**
- 修复机器人名称显示为空的问题
- 优化按钮和提示文案，提升用户体验
- 添加无机器人状态下的引导链接

**Non-Goals:**
- 不涉及后端 API 修改
- 不涉及数据模型变更
- 不涉及业务逻辑修改

## Decisions

**文案命名决策：**
- 使用"配置机器人"替代"编辑凭证"，更准确地描述功能：配置包含凭证设置，但不仅限于此，还包括其他机器人参数

**引导链接决策：**
- 使用 https://www.feishu.cn/ 作为占位链接，后续可替换为真实的飞书文档地址
- 在新标签页打开外部链接，避免用户丢失当前工作上下文

## Risks / Trade-offs

- **占位链接风险** → 后续需要替换为真实文档地址
