## ADDED Requirements

### Requirement: 创建项目时默认选中第一个头像
系统 SHALL 在打开创建项目弹框时自动选中第一个可用头像。

#### Scenario: 用户打开创建项目弹框
- **WHEN** 用户点击"创建项目"按钮打开弹框
- **THEN** 系统加载可用头像列表
- **AND** 自动选中列表中的第一个头像
- **AND** 显示该头像为选中状态

#### Scenario: 用户更改头像选择
- **WHEN** 用户点击其他头像
- **THEN** 系统更新选中状态为新点击的头像
- **AND** 取消第一个头像的选中状态
