## MODIFIED Requirements

### Requirement: 管理员可通过界面创建实例
系统应提供界面让管理员直接创建 OpenClaw 实例，无需经过审批流程。表单增加可选的飞书 AppID 和 AppSecret 字段，提交后切换为进度视图而非直接关闭弹窗。

#### Scenario: 打开展示创建弹窗
- **WHEN** 管理员点击「创建实例」按钮
- **THEN** 系统显示创建弹窗，包含实例名称输入框、目标用户选择器、可选的飞书 AppID 和 AppSecret 输入

#### Scenario: 填写表单并提交
- **WHEN** 管理员填写实例名称（2-50字符）
- **AND** 管理员选择目标用户
- **AND** 管理员点击「创建」按钮
- **THEN** 系统提交创建请求
- **AND** 弹窗切换为进度视图

#### Scenario: 创建成功
- **WHEN** 创建请求成功且所有进度步骤完成
- **THEN** 系统显示成功状态
- **AND** 用户点击「查看实例」后关闭弹窗并刷新列表

#### Scenario: 创建失败 - 名称已存在
- **WHEN** 创建请求返回名称冲突错误
- **THEN** 系统在名称字段下方显示错误「实例名称已存在」
- **AND** 保持表单视图打开状态

#### Scenario: 创建失败 - 服务端错误
- **WHEN** 创建请求返回服务端错误
- **THEN** 系统显示错误提示「创建失败，请稍后重试」
- **AND** 保持表单视图打开状态
