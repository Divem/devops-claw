## Context

当前 OpenClawAdmin.vue 已实现左侧固定侧边导航（220px）+ 右侧内容区的全屏布局。侧边导航包含 10 个菜单项（聊天、概览、通道、实例、会话、使用情况、定时任务、配置、日志、文档），其中「配置」菜单项指向 `/code` 路径。

参考飞书 OpenClaw Gateway Dashboard 代码模式截图（`docs/images/13openclaw-管理面板-代码模式.png`），代码模式是一个独立的沉浸式视图，与控制台模式（侧边导航布局）完全不同。

## Goals / Non-Goals

**Goals:**
- 在管理页面添加控制台/代码模式的切换能力
- 代码模式下隐藏侧边导航，内容区全宽展示代码编辑器 iframe
- 侧边导航顶部提供模式切换入口
- 切换时 iframe 重新加载对应内容

**Non-Goals:**
- 不实现代码编辑器本身（仍通过 iframe 嵌入 Gateway）
- 不修改 Gateway 反向代理逻辑
- 不引入 vue-router 进行模式间路由切换

## Decisions

### 1. 模式切换位置：侧边导航顶部项目信息区

在侧边导航的「去对话」按钮旁添加「代码模式」切换按钮，点击后切换到代码模式视图。代码模式下侧边导航收起为窄条（仅显示图标和返回按钮），顶部提供「控制台」按钮切回。

**替代方案：** 顶部 Tab 切换 — 不采用，因为这会打破侧边导航的设计语言。

### 2. 代码模式布局

代码模式下侧边导航折叠为窄条（60px），仅显示：
- 返回按钮
- 模式切换按钮（切回控制台）
- 纵向排列的菜单图标（无文字）

右侧内容区自动扩展填充剩余空间，iframe src 指向 Gateway 代码编辑路由 `/code`。

**替代方案：** 完全隐藏侧边导航 — 不采用，因为用户仍需快速切换回控制台，保留折叠导航提供操作入口。

### 3. 状态管理

使用组件内的 `ref<boolean>` (`isCodeMode`) 管理模式状态，不需要持久化到 URL 或 store。刷新页面后回到默认的控制台模式。

### 4. 切换动画

侧边导航宽度变化使用 CSS transition 动画（0.3s），内容区宽度自动跟随 flex 布局调整。

## Risks / Trade-offs

- **[侧边导航折叠时菜单不可点击]** → 代码模式下折叠导航仅提供返回和模式切换功能，菜单项不响应点击，用户需先切回控制台模式
- **[iframe 重新加载]** → 模式切换时 iframe src 改变会触发重新加载，有短暂骨架屏闪烁
- **[状态不持久化]** → 刷新页面会回到控制台模式，但这符合 iframe 嵌入的临时性特征
