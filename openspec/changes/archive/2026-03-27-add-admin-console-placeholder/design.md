## Context

OpenClaw 是一个基于 Vue 3 + TypeScript 的企业级 DevOps 平台。当前控制台页面需要添加一个视觉占位符，用于标识当前处于管理员控制台界面。使用 `docs/images/99openclaw-admin.png` 作为占位图片，显示在页面上方。

当前技术栈：
- Vue 3 Composition API
- TypeScript
- Tailwind CSS v4
- Less (scoped styles)
- Naive UI 组件库

## Goals / Non-Goals

**Goals:**
- 在 `projects/proj-001/admin` 控制台页面上方显示 admin 占位图片
- 图片使用 `docs/images/99openclaw-admin.png`
- 图片样式合适，不影响下方控制台内容的正常显示
- 保持代码简洁，符合现有代码规范

**Non-Goals:**
- 不添加复杂的交互功能
- 不修改控制台原有的业务逻辑
- 不引入新的依赖库

## Decisions

### 1. 图片位置：页面上方居中显示
**决策**: 将图片放置在控制台内容区域的上方，采用居中布局
**理由**: 居中显示更加美观，且符合设计规范。图片作为视觉标识，不应干扰主要内容
**替代方案**: 左侧显示 - 但考虑到控制台页面布局，居中更协调

### 2. 图片尺寸：固定高度，自适应宽度
**决策**: 设置固定高度（如 200px），宽度自适应保持比例
**理由**: 确保图片不会过大占据过多空间，同时保持图片原始比例不被拉伸变形

### 3. 样式方案：使用 Tailwind CSS + scoped Less
**决策**: 使用 Tailwind 工具类进行基础布局，scoped Less 进行特定样式调整
**理由**: 与项目现有技术栈保持一致，保持代码规范

### 4. 文件修改位置
**决策**: 修改控制台对应的 Vue 组件文件，在模板顶部添加图片元素
**理由**: 最小化改动范围，直接在最相关的地方添加功能

## Risks / Trade-offs

- **[风险]** 图片路径可能不存在 → **缓解**: 在实现前验证 `docs/images/99openclaw-admin.png` 是否存在，如不存在需要创建该图片或使用占位符
- **[风险]** 图片尺寸可能影响页面布局 → **缓解**: 使用固定高度容器，确保无论图片尺寸如何都不会破坏页面结构
- **[风险]** 响应式适配问题 → **缓解**: 使用 Tailwind 的响应式类，在移动端适当缩小图片尺寸
