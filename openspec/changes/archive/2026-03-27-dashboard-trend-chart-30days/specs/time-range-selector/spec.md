## ADDED Requirements

### Requirement: 预设时间范围快速选择
时间范围选择器 SHALL 提供常用时间范围的快捷按钮。

#### Scenario: 显示预设选项
- **WHEN** 用户打开 Dashboard 页面
- **THEN** 时间筛选器显示预设按钮：近7天、近30天、近90天、自定义
- **AND** "近30天" 默认为选中状态

#### Scenario: 点击预设按钮
- **WHEN** 用户点击 "近7天" 按钮
- **THEN** 按钮切换为激活状态
- **AND** 趋势图立即更新显示 7 天数据
- **AND** 自定义日期范围选择器隐藏

### Requirement: 自定义日期范围选择
时间范围选择器 SHALL 支持用户选择任意日期范围。

#### Scenario: 打开自定义选择
- **WHEN** 用户点击 "自定义" 按钮
- **THEN** 显示日期范围选择器（开始日期 - 结束日期）
- **AND** 预设按钮切换为非激活状态

#### Scenario: 选择有效日期范围
- **WHEN** 用户选择开始日期为 2024-01-01，结束日期为 2024-01-31
- **THEN** 趋势图显示该范围内的数据
- **AND** 日期选择器显示选中范围

#### Scenario: 选择无效日期范围
- **WHEN** 用户选择开始日期晚于结束日期
- **THEN** 显示错误提示："开始日期不能晚于结束日期"
- **AND** 不触发趋势图更新

#### Scenario: 超出最大跨度限制
- **WHEN** 用户选择的日期范围超过 90 天
- **THEN** 显示警告提示："时间范围不能超过 90 天"
- **AND** 自动截断至最大允许范围

### Requirement: 日期选择器 UI 规范
时间范围选择器 SHALL 符合系统 UI 设计规范。

#### Scenario: 使用 Naive UI 组件
- **WHEN** 日期选择器渲染
- **THEN** 使用 Naive UI 的 `n-date-picker` 组件
- **AND** 样式与系统主题一致（圆角、颜色、间距）

#### Scenario: 本地化显示
- **WHEN** 日期选择器打开
- **THEN** 日历显示为中文（周一到周日）
- **AND** 日期格式为 YYYY-MM-DD
