## Why

在 admin openclaw 配置页面中，用户点击"去对话"按钮后弹出的对话弹框会被页面中的控制台图片遮挡，导致用户无法正常查看和交互。这是一个严重的 UI 体验问题，需要修复弹框的层级确保其始终位于最顶层。

## What Changes

- 修复对话弹框的 z-index 层级问题，确保其显示在所有页面元素（包括控制台图片）之上
- 检查并调整弹框组件的 CSS 样式，添加适当的 `z-index` 值
- 确保弹框的遮罩层（mask/overlay）也具有足够的层级
- 验证弹框在不同浏览器和设备上的显示效果

## Capabilities

### New Capabilities
- `dialog-z-index-fix`: 修复弹框层级问题，确保对话弹框正确显示在最顶层

### Modified Capabilities
<!-- 此变更不涉及现有功能规范的修改，仅修复 UI 层级的实现问题 -->

## Impact

- 受影响的文件：admin openclaw 配置页面相关组件
- 影响的组件：对话弹框组件、控制台图片容器
- 用户体验：用户在配置页面可以正常使用对话功能
- 无 API 变更或破坏性变更
