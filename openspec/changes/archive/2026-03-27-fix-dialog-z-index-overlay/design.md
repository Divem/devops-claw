## Context

当前 admin openclaw 配置页面中的对话弹框存在 z-index 层级问题，导致弹框被页面中的控制台图片遮挡。这影响了用户的正常使用体验。

## Goals / Non-Goals

**Goals:**
- 修复对话弹框的 z-index 层级，确保其显示在所有页面元素之上
- 确保弹框的遮罩层（overlay）也具有正确的层级
- 保持代码的一致性和可维护性

**Non-Goals:**
- 不修改弹框的交互逻辑或功能行为
- 不改变控制台图片的显示方式
- 不影响其他页面的弹框组件

## Decisions

**使用更高的 z-index 值**
- 将对话弹框的 z-index 设置为 `2000` 或更高，确保高于控制台图片（通常在 100-1000 范围）
- 使用 Tailwind CSS 的 `z-50` 或自定义 CSS 的 `z-index: 2000`

**确保遮罩层层级**
- 弹框的遮罩层（overlay/backdrop）也需要设置适当的 z-index
- 遮罩层 z-index 应略低于弹框本体，但高于页面其他内容

**CSS 定位检查**
- 确认弹框组件使用 `position: fixed` 或 `position: absolute`
- 检查父元素是否设置了 `position: relative` 创建了新的层叠上下文

**方案对比：**
- 方案 A：修改全局 z-index 变量（过度设计）
- 方案 B：仅修改该弹框组件的样式（选中，针对性强，影响范围小）

## Risks / Trade-offs

- [风险] 设置过高的 z-index 可能影响其他重要 UI 元素 → [缓解] 使用 2000，留有足够的中间值空间
- [风险] 层叠上下文问题可能导致 z-index 不生效 → [缓解] 检查父元素定位属性
- [风险] 其他弹框组件可能有类似问题 → [缓解] 统一检查所有弹框组件的 z-index
