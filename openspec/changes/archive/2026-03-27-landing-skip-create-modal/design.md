## Context

当前落地页（Landing Page）的"立即部署"按钮会将用户导航到创建页面并自动弹出创建弹框。根据用户体验最佳实践，自动弹框会打断用户的浏览流程。需要移除这种自动触发行为，让用户自主选择何时创建项目。

## Goals / Non-Goals

**Goals:**
- 移除从落地页跳转时自动弹出创建弹框的行为
- 保持创建页面的正常功能和布局
- 用户需要主动点击"创建"按钮才会看到弹框

**Non-Goals:**
- 不修改创建弹框的内部逻辑
- 不修改落地页的视觉设计
- 不修改路由跳转逻辑

## Decisions

**决策 1: 修改 landing-page spec 而非新增 spec**
- 理由：这是现有行为的变更，不需要新增能力
- 替代方案：创建新的 create-page spec（过于复杂，不必要）

**决策 2: 仅修改 spec 中的场景描述**
- 理由：实现简单，只需要移除自动弹框的状态设置
- 影响：测试用例需要相应更新

## Risks / Trade-offs

**风险：用户可能不清楚如何创建项目**
- 缓解措施：创建页面有明确的"创建 OpenClaw"按钮，用户很容易发现

**风险：现有测试依赖自动弹框行为**
- 缓解措施：同步更新测试用例
