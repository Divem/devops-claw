## Why

OpenClaw 配置页面需要一个专业的代码编辑模式,方便用户直接编辑配置文件。目前缺少类似 VS Code 的专业代码编辑体验,用户无法高效地浏览和编辑复杂的 JSON/YAML 配置文件。通过提供代码模式,可以显著提升开发者体验,让配置管理更加直观和高效。

## What Changes

- **新增代码模式界面**: 实现类似 VS Code 的代码编辑器界面,包含以下功能模块:
  - 左侧文件资源管理器:展示配置文件树结构,支持文件夹展开/折叠
  - 顶部面包屑导航:显示当前文件的完整路径
  - 标签页系统:支持多文件同时打开和切换
  - 代码编辑区域:支持语法高亮、行号显示
  - 底部状态栏:显示文件信息、光标位置等
- **文件操作功能**: 支持新建、删除、重命名文件和文件夹
- **配置持久化**: 编辑内容自动保存到后端
- **响应式设计**: 适配不同屏幕尺寸

## Capabilities

### New Capabilities

- `code-editor`: 代码编辑器核心功能,包括 Monaco Editor 集成、语法高亮、代码提示
- `file-explorer`: 文件资源管理器,支持树形展示、文件夹操作、文件搜索
- `tab-management`: 标签页管理,支持多文件打开、标签切换、未保存标记
- `breadcrumb-navigation`: 面包屑导航,显示文件路径,支持快速跳转

### Modified Capabilities

- 无

## Impact

- **前端代码**: 新增 `src/views/config/` 目录下的代码模式相关组件
- **路由配置**: 在配置页面路由中添加代码模式子路由
- **依赖**: 新增 `@monaco-editor/loader` 或 `monaco-editor` 用于代码编辑
- **状态管理**: 需要管理文件树状态、打开的标签页状态、当前编辑内容状态
- **API 接口**: 需要后端提供文件 CRUD 接口、配置保存接口
