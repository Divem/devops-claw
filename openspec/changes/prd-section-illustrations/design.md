## Context

PRD 文档 `public/html/prd.html` 是一个纯静态 HTML 文件，不参与 Vue 构建流程。当前文档使用 Mermaid 图表、表格和文字描述产品需求，但缺乏视觉原型图来辅助理解界面设计。

文档已有一套完整的 CSS 样式体系（CSS 变量、排版、表格、信息框等），原型图需要融入这套风格。

## Goals / Non-Goals

**Goals:**

- 在每个页面/功能章节插入轻量级 HTML/CSS 原型图，直观展示 UI 布局和交互元素
- 原型图风格统一，使用 PRD 现有的 CSS 变量（`--primary`、`--border`、`--bg-page` 等）
- 原型图纯 HTML/CSS 实现，无外部图片依赖，确保离线可访问
- 原型图容器自适应，响应式适配移动端

**Non-Goals:**

- 不使用真实截图或外部图片（PNG/SVG 文件）
- 不实现可交互的完整原型，仅为静态展示
- 不修改 PRD 的文字内容或章节结构
- 不影响 PRD 的打印样式（原型图在打印时应正常显示）

## Decisions

### 1. 原型图实现方式：内联 HTML/CSS

**选择**: 在 PRD HTML 文件内直接编写 HTML/CSS 原型图

**替代方案**:
- 外部 SVG/PNG 图片 → 需要管理图片资源，且无法使用 CSS 变量保持风格统一
- iframe 嵌入独立原型文件 → 增加文件管理复杂度，样式无法共享
- JavaScript 动态渲染 → 增加 PRD 复杂度，违背静态文档原则

**理由**: PRD 是纯静态 HTML，内联 HTML/CSS 零依赖、离线可用、与现有样式无缝融合。

### 2. 原型图样式策略：复用 + 扩展

**选择**: 复用 PRD 现有 CSS 变量，新增 `.prd-mockup` 系列类

**方案**:
- `.prd-mockup` — 原型图容器（浅灰背景、圆角边框、内边距）
- `.prd-mockup-title` — 原型图标题（"页面原型" 标签）
- `.prd-mockup-browser` — 浏览器外框（地址栏 + 内容区）
- `.prd-mockup-component` — 组件占位符（按钮、输入框、卡片等基础元素）
- `.prd-mockup-status` — 状态标签（创建中/已部署/审批中等）

### 3. 原型图详细程度：中保真线框图

**选择**: 使用带颜色和图标的线框图风格，而非纯灰度线框

**理由**: PRD 已定义完整的配色体系（`--primary: #006eff`、状态色等），原型图使用真实配色帮助读者更直观理解最终效果。

### 4. 插入位置策略：章节标题后

**选择**: 在每个 `<h4>` 章节标题之后、详细文字说明之前插入原型图

**理由**: 读者先看到原型图建立视觉印象，再阅读文字细节，降低认知负担。

## Risks / Trade-offs

- **[PRD 文件体积增大]** → 预计增加 30-50KB，对静态 HTML 可接受。原型图 HTML 较冗长，但无性能影响。
- **[维护同步]** → 原型图与实际实现可能产生偏差 → 在原型图标题中注明"仅供参考，以实际实现为准"的免责说明。
- **[移动端显示]** → 复杂原型图在小屏幕可能截断 → 使用 `overflow-x: auto` 允许横向滚动。
