## Why

PRD 文档目前以纯文字+表格+Mermaid 图表为主，缺乏视觉原型图，读者需要大量文字想象产品界面。通过在每个页面章节嵌入 HTML/CSS 原型配图，让产品经理、设计师、开发人员直观理解产品设计，降低沟通成本。

## What Changes

- 在 `public/html/prd.html` 中为每个页面/功能章节添加内联 HTML/CSS 原型图（mockup）
- 新增 CSS 类 `.prd-mockup` 用于统一原型图容器样式（浅灰背景、圆角边框、比例约束）
- 为以下章节添加原型配图：
  - 6.0 产品落地页（Landing Page 全页原型）
  - 6.2.1 首页空状态引导
  - 6.2.2 项目列表展示
  - 6.2.3 创建项目 - 步骤一
  - 6.2.4 创建项目 - 步骤二
  - 6.2.5 创建进度展示
  - 6.2.6 创建完成弹窗
  - 6.3.1 顶部工具栏 + 6.3.2 视图模式切换
  - 6.3.3 控制台模式
  - 6.3.5 代码模式
  - 6.3.6 终端模式
  - 7.2.1 统计卡片网格
  - 7.2.2 资源使用进度条
  - 7.2.3 创建趋势图
  - 7.2.4 待办事项列表
  - 7.4.1 实例列表
  - 7.4.2 实例详情抽屉
  - 7.5.5 审批卡片组件
  - 7.6 全局配置
  - 8. 认证系统登录弹窗

## Capabilities

### New Capabilities

- `prd-mockup-styles`: PRD 原型图通用 CSS 样式体系（容器、布局、组件占位符、状态标签等基础样式）
- `prd-employee-mockups`: 员工端页面原型图（首页空状态、项目列表、创建流程、项目配置三模式等）
- `prd-admin-mockups`: 管理端页面原型图（仪表盘、实例管理、审批管理、全局配置、登录弹窗等）

### Modified Capabilities

（无现有 spec 需要修改，本次变更新增独立的前端静态资源）

## Impact

- **文件变更**: `public/html/prd.html`（新增 CSS 样式 + 各章节原型图 HTML）
- **文件体积**: 预计增加 30-50KB（纯 HTML/CSS，无外部图片依赖）
- **构建依赖**: 无，PRD 是纯静态 HTML，不参与 Vue 构建
- **兼容性**: 不影响现有页面内容，原型图以独立容器插入
