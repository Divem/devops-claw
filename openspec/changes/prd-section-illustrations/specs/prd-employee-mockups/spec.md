## ADDED Requirements

### Requirement: 员工端 - 首页空状态引导原型图
PRD 6.2.1 章节 SHALL 包含首页空状态引导的原型图，展示：居中布局、空状态图标/插画、引导文案"还没有 OpenClaw 项目"、"立即部署"按钮、底部三个特性卡片（一键部署、飞书集成、数据安全）。

#### Scenario: 空状态原型图正确插入
- **WHEN** 读者浏览到 PRD 6.2.1 章节标题下方
- **THEN** 看到居中空状态引导的原型图，包含图标占位符和"立即部署"按钮

### Requirement: 员工端 - 项目列表展示原型图
PRD 6.2.2 章节 SHALL 包含项目列表的原型图，展示：2-3 个项目卡片网格排列，每个卡片包含：头像、项目名称、状态标签（创建中/已部署/审批中）、操作按钮组。

#### Scenario: 项目列表原型图包含多种状态
- **WHEN** 读者浏览到 PRD 6.2.2 章节标题下方
- **THEN** 原型图展示至少 3 种不同状态的项目卡片（创建中、已部署、审批中）

### Requirement: 员工端 - 创建项目步骤一原型图
PRD 6.2.3 章节 SHALL 包含设置项目名弹窗的原型图，展示：Modal 遮罩层、弹窗标题"创建 OpenClaw"、输入框（placeholder"请输入项目名称"）、步骤指示器（步骤一高亮）、"下一步"按钮。

#### Scenario: 创建步骤一原型图展示弹窗布局
- **WHEN** 读者浏览到 PRD 6.2.3 章节标题下方
- **THEN** 看到居中 Modal 弹窗原型图，含步骤指示器和输入框

### Requirement: 员工端 - 创建项目步骤二原型图
PRD 6.2.4 章节 SHALL 包含配置飞书渠道弹窗的原型图，展示：步骤指示器（步骤二高亮）、头像选择网格（6-8 个圆形头像）、机器人配置折叠面板、"创建"按钮。

#### Scenario: 创建步骤二原型图展示头像选择器
- **WHEN** 读者浏览到 PRD 6.2.4 章节标题下方
- **THEN** 原型图展示头像网格和一个选中状态的示例

### Requirement: 员工端 - 创建进度展示原型图
PRD 6.2.5 章节 SHALL 包含三步进度条的原型图，展示：三个步骤（启动云端电脑、启动 OpenClaw、连接飞书），其中前两步完成（打勾），第三步进行中（旋转图标），每步显示耗时。

#### Scenario: 进度条原型图展示步骤状态
- **WHEN** 读者浏览到 PRD 6.2.5 章节标题下方
- **THEN** 原型图展示三步进度条，包含已完成和进行中两种状态

### Requirement: 员工端 - 创建完成弹窗原型图
PRD 6.2.6 章节 SHALL 包含成功弹窗的原型图，展示：成功图标、"部署完成"标题、提示文案（审批中）、"打开 OpenClaw 项目"和"查看审批单"两个操作按钮。

#### Scenario: 创建完成原型图展示成功弹窗
- **WHEN** 读者浏览到 PRD 6.2.6 章节标题下方
- **THEN** 看到绿色成功图标和两个操作按钮

### Requirement: 员工端 - 项目配置管理原型图
PRD 6.3 章节 SHALL 包含项目配置页面的原型图，展示：顶部工具栏（返回按钮 + 项目名 + 状态标签 + 视图切换按钮组 + 机器人信息下拉），以及三个视图模式的标签切换展示：控制台（左侧导航 + 右侧 iframe）、代码模式（左侧文件树 + 右侧编辑器）、终端模式（深色终端界面 + 系统信息）。

#### Scenario: 配置管理原型图展示三模式布局
- **WHEN** 读者浏览到 PRD 6.3 章节标题下方
- **THEN** 原型图展示控制台模式的完整布局（左侧导航菜单 + 右侧内容区）

#### Scenario: 代码模式原型图展示编辑器布局
- **WHEN** 读者浏览到 PRD 6.3.5 章节标题下方
- **THEN** 原型图展示左侧文件树和右侧 Monaco 编辑器区域

#### Scenario: 终端模式原型图展示深色界面
- **WHEN** 读者浏览到 PRD 6.3.6 章节标题下方
- **THEN** 原型图展示深色背景终端界面，包含系统信息和 YAML 配置预览

### Requirement: 员工端 - 产品落地页原型图
PRD 6.0 章节 SHALL 包含 Landing Page 的原型图，展示：Hero 区域（大标题 + CTA 按钮）、三栏特性卡片（一键部署、原生体验、数据安全）、统计数据区域。

#### Scenario: 落地页原型图展示完整布局
- **WHEN** 读者浏览到 PRD 6.0 章节标题下方
- **THEN** 原型图展示 Landing Page 的 Hero 区域和特性卡片
