## ADDED Requirements

### Requirement: 管理端 - 仪表盘统计卡片原型图
PRD 7.2.1 章节 SHALL 包含统计卡片网格的原型图，展示：4 个统计卡片（实例总数、运行中、已停止、异常），每个卡片包含图标、数字、标签，异常卡片带红色警示边框。

#### Scenario: 统计卡片原型图正确展示四种状态
- **WHEN** 读者浏览到 PRD 7.2.1 章节标题下方
- **THEN** 原型图展示 4 个统计卡片，异常卡片有红色警示效果

### Requirement: 管理端 - 资源使用进度条原型图
PRD 7.2.2 章节 SHALL 包含资源使用进度条的原型图，展示：4 个资源指标（CPU、内存、存储、网络），每个含名称、百分比数值和彩色进度条，进度条颜色根据使用率变化（蓝/黄/红）。

#### Scenario: 资源进度条原型图展示多种颜色
- **WHEN** 读者浏览到 PRD 7.2.2 章节标题下方
- **THEN** 原型图展示至少 3 种不同颜色的进度条（蓝色 <60%、黄色 60-80%、红色 >80%）

### Requirement: 管理端 - 创建趋势图原型图
PRD 7.2.3 章节 SHALL 包含创建趋势图的原型图，展示：折线图区域（X 轴为日期、Y 轴为数量）、时间范围选择器（7天/30天/90天）、数据点悬停效果。

#### Scenario: 趋势图原型图展示折线图布局
- **WHEN** 读者浏览到 PRD 7.2.3 章节标题下方
- **THEN** 原型图展示折线图占位区域和时间范围选择器

### Requirement: 管理端 - 待办事项列表原型图
PRD 7.2.4 章节 SHALL 包含待办事项列表的原型图，展示：3-4 条待办事项，每条包含类型图标、标题、描述和操作按钮，不同类型使用不同颜色标识。

#### Scenario: 待办列表原型图展示多种待办类型
- **WHEN** 读者浏览到 PRD 7.2.4 章节标题下方
- **THEN** 原型图展示至少 2 种不同类型的待办事项（审批、异常）

### Requirement: 管理端 - 实例列表原型图
PRD 7.4.1 章节 SHALL 包含实例管理表格的原型图，展示：表头（实例名称、所属员工、虚拟机状态、飞书连接状态、创建时间、操作）、3-4 行示例数据、状态标签（运行中/已停止/异常）、操作按钮组。

#### Scenario: 实例列表原型图展示表格布局
- **WHEN** 读者浏览到 PRD 7.4.1 章节标题下方
- **THEN** 原型图展示完整的表格布局，含筛选区域和数据行

### Requirement: 管理端 - 实例详情抽屉原型图
PRD 7.4.2 章节 SHALL 包含实例详情抽屉的原型图，展示：从右侧滑出的抽屉面板，包含基本信息区、虚拟机信息区、服务状态区、操作按钮区。

#### Scenario: 实例详情抽屉原型图展示侧边面板
- **WHEN** 读者浏览到 PRD 7.4.2 章节标题下方
- **THEN** 原型图展示右侧抽屉面板布局

### Requirement: 管理端 - 审批卡片原型图
PRD 7.5.5 章节 SHALL 包含审批卡片的原型图，展示：卡片布局含员工信息区（头像+姓名+时间）、实例信息区（名称+AppID+状态）、操作按钮区（"去配置"+"标记完成"）。

#### Scenario: 审批卡片原型图展示待审批状态
- **WHEN** 读者浏览到 PRD 7.5.5 章节标题下方
- **THEN** 原型图展示待审批卡片，含完整信息层次和操作按钮

### Requirement: 管理端 - 全局配置原型图
PRD 7.6 章节 SHALL 包含全局配置页面的原型图，展示：三个配置分组（模型配置、Memory 配置、发布策略），每组含标签和输入框，底部有保存和重置按钮。

#### Scenario: 全局配置原型图展示表单布局
- **WHEN** 读者浏览到 PRD 7.6 章节标题下方
- **THEN** 原型图展示分组表单布局，含多种输入控件

### Requirement: 管理端 - 登录弹窗原型图
PRD 7.7 章节 SHALL 包含全局登录弹窗的原型图，展示：Modal 弹窗、Logo 图标、"登录 DevOps OpenClaw"标题、用户名输入框、密码输入框、"登录"按钮。

#### Scenario: 登录弹窗原型图展示表单布局
- **WHEN** 读者浏览到 PRD 7.7 章节标题下方
- **THEN** 原型图展示居中登录弹窗，含用户名和密码输入框
