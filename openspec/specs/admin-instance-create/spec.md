## ADDED Requirements

### Requirement: 管理员可通过界面创建实例
系统应提供界面让管理员直接创建 OpenClaw 实例，无需经过审批流程。

#### Scenario: 打开展示创建弹窗
- **WHEN** 管理员点击「创建实例」按钮
- **THEN** 系统显示创建弹窗，包含实例名称输入框和目标用户选择器

#### Scenario: 填写表单并提交
- **WHEN** 管理员填写实例名称（2-50字符）
- **AND** 管理员选择目标用户
- **AND** 管理员点击「创建」按钮
- **THEN** 系统提交创建请求
- **AND** 显示加载状态

#### Scenario: 创建成功
- **WHEN** 创建请求成功
- **THEN** 系统关闭弹窗
- **AND** 刷新实例列表
- **AND** 显示成功提示「实例创建成功」

#### Scenario: 创建失败 - 名称已存在
- **WHEN** 创建请求返回名称冲突错误
- **THEN** 系统在名称字段下方显示错误「实例名称已存在」
- **AND** 保持弹窗打开状态

#### Scenario: 创建失败 - 服务端错误
- **WHEN** 创建请求返回服务端错误
- **THEN** 系统显示错误提示「创建失败，请稍后重试」
- **AND** 保持弹窗打开状态

### Requirement: 用户选择器支持搜索
系统应提供用户选择器，支持按名称搜索企业员工和领导。

#### Scenario: 搜索用户
- **WHEN** 管理员在用户选择器输入框输入关键词
- **THEN** 系统显示匹配的用户列表（显示名称和头像）

#### Scenario: 选择用户
- **WHEN** 管理员点击搜索结果中的用户
- **THEN** 系统选中该用户
- **AND** 关闭下拉列表

#### Scenario: 清空选择
- **WHEN** 管理员点击已选用户的清除按钮
- **THEN** 系统清空用户选择
