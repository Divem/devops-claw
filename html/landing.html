部署: 内网 VM + Kubernetes + 飞书 OAuth

产品定位与背景

DevOps Claw 的定位是公司内部的 OpenClaw 托管服务，产品灵感来自飞书 OpenClaw（飞书版托管方案）。我们的目标是让每位员工都能像使用飞书 OpenClaw 一样，轻松拥有专属 AI 助手，同时确保所有数据留在公司内部。

  • OpenClaw → 飞书 OpenClaw → DevOps Claw
  • 模仿飞书 OpenClaw 的产品体验
  • 适配公司现有的基础设施和安全要求
  • 面向内部员工，完全免费

常见问题

关于 DevOps Claw 的内部常见问题解答

DevOps Claw 是什么？和飞书 OpenClaw 有什么关系？ +
DevOps Claw 是公司内部自建的 OpenClaw（开源 AI 助手平台）托管服务，产品灵感来自飞书 OpenClaw。简单理解：OpenClaw 是开源项目，飞书 OpenClaw 是飞书提供的托管版本，DevOps Claw 是我们公司内部搭建的版本。区别在于所有数据运行在公司内网，安全可控。
如何创建自己的 AI 助手？ +
登录平台后，在首页点击"创建助手"按钮，填写助手名称和基本配置即可。系统会自动完成 VM 分配、OpenClaw 安装等底层操作，通常几分钟内就能完成。创建成功后，你可以通过 Gateway Dashboard 进行个性化配置。
创建 AI 助手需要管理员审批吗？ +
实例创建本身是自动化的，不需要审批。但如果你想将 AI 助手接入飞书对话，需要管理员审批飞书长连接申请并完成 WebSocket 对接配置。这是为了确保飞书集成的安全性和规范性。
我的对话数据安全吗？ +
所有 AI 助手实例运行在公司内网，对话数据全程在企业内部流转，不会经过外部网络。平台还提供操作审计日志，关键操作都有记录可追溯。你可以放心在助手中讨论工作相关的内容。
遇到问题应该找谁？ +
如果是使用问题，可以在飞书群"DevOps Claw 交流群"中提问。如果是实例运行异常或功能 Bug，可以通过飞书机器人提交工单，DevOps 团队会尽快响应处理。
可以安装自定义插件吗？ +
可以。通过 Gateway Dashboard 可以安装 OpenClaw 官方插件和社区插件。如果你需要开发自定义插件来对接公司内部系统，可以联系 DevOps 团队获取技术支持。
