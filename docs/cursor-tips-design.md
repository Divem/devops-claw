# Cursor Tips 交互设计参考

光标停留时在鼠标附近浮现引导文案的轻量交互模式。

---

## 交互逻辑

```
鼠标进入区域
    │
    ├─ 移动中 ──────────────→ 不显示 / 立即隐藏
    │
    └─ 停留 1.5s
           │
           └─ 显示 Tips（打字机逐字出现）
                  │
                  ├─ 每 3s 自动切换下一条（循环）
                  │
                  └─ 鼠标再次移动 ──→ 立即隐藏，重新计时
```

触发条件（满足其一即可）：
- 鼠标在目标区域内停止移动 1.5 秒
- 页面滚动停止 1.5 秒（且目标区域在视口内）
- 页面加载后目标区域可见，无任何操作 1.5 秒

---

## 视觉样式

**无背景、无气泡、无阴影**，文字直接浮在页面上。

```
位置：光标左对齐，上方 28px
格式："文案内容"（左引号先出现，右引号打字结束后补全）
字体：13px / 600 / italic
颜色：rgba(40, 40, 40, 0.9)
出现：opacity 淡入 0.15s，无位移
消失：opacity 淡出 0.15s，无位移
```

示例效果：
```
"终于不用折腾环境啦，一键安装太省心～"
        ↑
      光标
```

---

## 文案原则

围绕三个维度写，每条控制在 20 字以内：

| 维度 | 示例 |
|------|------|
| 用户痛点共鸣 | 终于不用折腾环境啦，一键安装太省心～ |
| 平台价值传递 | OpenClaw 官方纯净版，安全无捆绑 |
| IP 拟人情绪 | 小龙虾探头：主人快带我回家～ |

## 实现文件

| 文件 | 职责 |
|------|------|
| `src/composables/useCursorTips.ts` | 触发逻辑：鼠标停留检测、滚动停留检测、IntersectionObserver、文案循环 |
| `src/components/CursorTips.vue` | 渲染：Teleport 到 body、fixed 定位、打字机动效 |

### 关键参数

```ts
useCursorTips({
  tips: string[],          // 文案数组
  scrollPauseDelay: 1500,  // 停留触发延迟（ms）
  switchInterval: 3000,    // 文案切换间隔（ms）
  containerSelector: '.hero-section'  // 生效区域
})
```

### 定位计算

```ts
// 光标左对齐、上方 28px
transform: `translate(${x}px, ${y - 28}px)`
```

### 打字机速度

```ts
45ms / 字符  // ~22 字/秒，自然语速感
```
