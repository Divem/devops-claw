# DevOps OpenClaw 产品功能规格说明书

> 版本：v1.3 | 更新日期：2026-03-27
> 
> 本文档为 PRD 的补充说明，详细描述每个页面和功能的规格

---

## 文档说明

### 功能规格说明格式

每个功能规格包含以下要素：

| 要素 | 说明 |
|------|------|
| **触发条件** | 触发该功能的前提条件、用户操作、系统状态 |
| **用户场景** | 典型用户故事，描述谁在什么情况下使用此功能 |
| **交互跳转说明** | 页面跳转、状态变化、事件触发、接口调用 |
| **预期结果** | 功能执行后的界面变化、数据变化、系统响应 |
| **异常情况** | 可能出现的异常场景、错误状态、降级方案 |
| **约束条件** | 限制条件、边界情况、安全要求、性能指标 |

## 第一章：产品落地页（Landing Page）

### 页面概述

产品对外宣传页面，展示核心价值主张，引导用户开始使用。

---

### 1.1 页面访问

#### 功能规格

**触发条件：**
- 用户首次访问系统根路径 `/`
- 用户点击导航栏"产品介绍"链接
- 外部推广链接跳转

**交互跳转说明：**
- 页面加载时自动展示
- 无需登录即可访问
- 右上角提供"立即开始"按钮，跳转至首页（需登录）

**预期结果：**
- 页面完整展示产品卖点：一键部署、原生体验、数据安全
- 展示统计数据：100+ 企业客户、99.9% 可用性、<5min 部署时间
- CTA 按钮引导用户行动

**约束条件：**
- 页面需要响应式适配，支持移动端浏览
- 加载时间需 < 3 秒
- 需要 SEO 优化，包含 meta 标签

**用户场景：**
- **场景1 - 外部推广引流**：潜在用户通过社交媒体或邮件推广链接访问，首次了解产品
- **场景2 - 产品介绍查看**：已登录用户在导航栏点击"产品介绍"，查看产品详情
- **场景3 - 移动端查看**：用户在手机或平板上通过飞书分享链接访问落地页

**异常情况：**
| 异常场景 | 现象 | 处理方式 |
|---------|------|---------|
| 页面加载超时 | 用户访问时页面长时间白屏（> 5秒） | 显示加载失败提示，提供"重试"按钮，记录错误日志 |
| 资源加载失败 | 图片、图标等静态资源加载失败 | 降级显示文本描述，控制台输出错误，不影响核心功能 |
| JavaScript 执行错误 | 页面交互功能失效 | 优雅降级为基础展示页面，关键CTA按钮保持可用 |

## 第二章：首页/引导创建页（Home Page）

### 页面概述

用户登录后的默认页面，展示已创建项目或引导创建新项目。

---

### 2.1 空状态引导

#### 功能规格

**触发条件：**
- 用户首次登录系统
- 用户删除了所有项目后返回首页
- URL 路径为 `/` 且项目列表为空

**交互跳转说明：**
1. 系统自动检测用户项目数量
2. 若项目数为 0，展示空状态引导
3. 展示三大特性卡片（一键部署、原生体验、数据安全）
4. 提供"立即部署"CTA 按钮

**预期结果：**
- 页面显示友好的引导文案和插图
- 明确告知用户下一步操作（点击"立即部署"）
- 展示产品核心卖点，建立信任

**约束条件：**
- 项目列表查询需在 500ms 内完成
- 空状态需友好的视觉设计，避免用户困惑
- 必须提供明确的操作入口

**用户场景：**
- **场景1 - 新员工首次登录**：员工小王刚加入公司，首次登录系统，看到空状态引导页，了解产品功能后点击"立即部署"创建第一个项目
- **场景2 - 删除所有项目后**：员工小李删除了所有测试项目后返回首页，看到空状态提醒，决定重新创建正式项目

**异常情况：**
| 异常场景 | 现象 | 处理方式 |
|---------|------|---------|
| 项目列表加载失败 | 空状态无法展示或持续显示加载中 | 显示"数据加载失败"提示，提供"刷新"按钮，5秒后自动重试一次 |
| 网络断开 | 用户处于离线状态 | 显示离线提示，建议检查网络连接，不显示创建按钮避免用户误操作 |
| 数据权限异常 | 用户无法获取自己的项目列表 | 显示权限错误页，引导联系管理员，记录安全审计日志 |

---

### 2.2 项目列表展示

#### 功能规格

**触发条件：**
- 用户已创建至少一个项目
- 用户从其他页面返回首页
- URL 路径为 `/` 且项目列表不为空

**交互跳转说明：**
1. 页面加载时调用 `/api/projects` 接口
2. 按创建时间倒序排列项目卡片
3. 每个卡片展示：头像、项目名称、状态标签
4. 提供操作按钮：配置 OpenClaw、机器人信息、删除

**预期结果：**
- 以卡片网格形式展示所有项目
- 状态标签实时反映项目状态（创建中/已部署/审批中/异常）
- 点击"配置 OpenClaw"跳转至项目配置管理页

**约束条件：**
- 最多展示 12 个项目，超出需分页
- 状态更新需要实时或准实时（轮询 30s）
- 项目名称最长 50 字符，超出显示省略号

**用户场景：**
- **场景1 - 查看所有项目**：员工小张管理3个OpenClaw项目，需要快速查看各项目运行状态
- **场景2 - 切换项目配置**：员工需要切换到另一个项目的配置页进行对比
- **场景3 - 清理过期项目**：员工识别出审批中的项目已废弃，点击删除按钮进行清理

**异常情况：**
| 异常场景 | 现象 | 处理方式 |
|---------|------|---------|
| 状态数据过期 | 卡片显示"已部署"但实际服务已停止 | 增加状态检查提示，点击状态标签可触发手动刷新 |
| 项目名称过长 | 项目名超过50字符显示异常 | 自动截断并显示省略号，悬停显示完整名称 |
| 批量操作卡顿 | 项目数量过多（>50个）时页面卡顿 | 启用虚拟滚动，只渲染可见区域的项目卡片 |
| 删除后状态未更新 | 删除成功后卡片仍显示 | 立即移除DOM并重新获取列表，避免缓存不一致 |

## 第三章：创建流程（Create Flow）

### 流程概述

用户创建 OpenClaw 项目的完整流程，包含项目信息填写、机器人配置、创建进度展示。

---

### 3.1 创建项目弹窗 - 步骤一：设置项目名

#### 功能规格

**触发条件：**
- 用户在首页点击"立即部署"或"创建"按钮
- 用户通过快捷入口触发创建流程

**交互跳转说明：**
1. 弹出 Modal 弹窗，遮罩层透明度 50%
2. 输入框自动聚焦，显示 placeholder"请输入项目名称"
3. 实时校验项目名称（长度 2-50 字符，仅支持中文、英文、数字、下划线）
4. 点击"下一步"或按 Enter 键进入步骤二

**预期结果：**
- 弹窗平滑动画出现（200ms ease-out）
- 输入框有明确的状态反馈（默认/聚焦/错误）
- 校验失败时显示错误提示文案
- 项目名称实时保存到本地状态

**约束条件：**
- 项目名称全局唯一，重复时提示"该项目名已存在"
- 不能为空或仅包含空白字符
- 不能使用系统保留字（如 admin、test、api 等）
- 弹窗支持 ESC 键关闭，点击遮罩层关闭

**用户场景：**
- **场景1 - 新项目创建**：员工小刘需要为团队创建一个DevOps助手，输入"team-devops-bot"作为项目名
- **场景2 - 名称冲突处理**：员工尝试使用已有名称，系统提示后更换为"team-devops-bot-2026"
- **场景3 - 快速取消**：员工误触创建按钮，按ESC快速关闭弹窗

**异常情况：**
| 异常场景 | 现象 | 处理方式 |
|---------|------|---------|
| 项目名称重复 | 输入已存在的项目名称 | 实时校验并显示红色提示"该项目名已存在，请更换"，禁用下一步按钮 |
| 包含特殊字符 | 输入"my bot!"等含特殊字符的名称 | 校验失败，提示"仅支持中文、英文、数字、下划线"，并标红非法字符 |
| 网络延迟导致校验超时 | 输入后长时间无校验反馈 | 显示"正在校验..."，3秒后超时显示"校验失败，请重试" |
| 输入框失焦后未保存 | 用户输入后直接关闭弹窗 | 提示"有未保存的更改，确定要离开吗？"确认对话框 |

---

### 3.2 创建项目弹窗 - 步骤二：配置飞书渠道

#### 功能规格

**触发条件：**
- 用户成功完成步骤一（输入有效项目名）
- 用户点击"下一步"按钮

**交互跳转说明：**
1. 显示头像选择器（网格展示 20+ 预设头像）
2. 提供"机器人配置"折叠面板（默认收起）
3. 若展开配置面板，显示 AppID 和 AppSecret 输入框
4. 提供"跳过此步骤，稍后配置"复选框
5. 点击"创建"按钮提交，进入创建进度页面

**预期结果：**
- 默认选中第一个头像
- 点击头像有选中状态反馈
- 配置面板展开/收起有平滑动画
- 表单数据验证通过后才能提交

**约束条件：**
- 若选择跳过配置，项目状态标记为"待配置"
- AppID 格式校验（以 cli_ 开头，16 位字符）
- AppSecret 最少 32 位字符
- 若填写了配置，必须两者都填写且格式正确
- 提供"返回上一步"按钮，可修改项目名称

**用户场景：**
- **场景1 - 完整配置**：员工小陈有飞书机器人凭证，填写完整的AppID和AppSecret
- **场景2 - 先跳过配置**：员工小马暂无凭证，选择"跳过此步骤"先创建项目
- **场景3 - 返回修改**：员工发现项目名有误，点击"返回上一步"修改

**异常情况：**
| 异常场景 | 现象 | 处理方式 |
|---------|------|---------|
| AppID格式错误 | 输入"abc123"等非标准格式 | 校验失败，提示"AppID格式错误，应以cli_开头" |
| AppSecret过短 | 输入少于32位字符 | 校验失败，提示"AppSecret长度不足32位" |
| 只填其中一个 | 仅填写AppID未填AppSecret | 提示"请同时填写AppID和AppSecret，或选择跳过" |
| 凭证验证失败 | 提交后后端验证凭证无效 | 显示错误"飞书凭证验证失败，请检查是否正确"，不关闭弹窗 |
| 头像选择卡顿 | 头像网格加载缓慢 | 显示骨架屏占位，加载完成后平滑过渡 |

---

### 3.3 创建进度展示

#### 功能规格

**触发条件：**
- 用户点击"创建"按钮提交表单
- 后端返回创建任务 ID

**交互跳转说明：**
1. 进入创建进度页面，显示三步进度条
2. 通过 WebSocket 实时接收进度更新
3. 每步显示：步骤名称、状态图标、耗时
4. 步骤 2（启动 OpenClaw）完成后，可点击跳转至步骤 3
5. 完成后显示成功/失败弹窗

**预期结果：**
- 进度条实时更新，步骤完成后打勾
- 显示每个步骤的开始时间和耗时
- 任意步骤失败时，显示错误信息和重试按钮
- 成功后显示"部署完成"提示和下一步操作按钮

**约束条件：**
- WebSocket 连接失败时，降级为轮询（5s 间隔）
- 总超时时间：10 分钟，超时显示失败
- 步骤可点击跳转仅限：步骤 2 完成后可跳至步骤 3
- 页面刷新后，若创建中则恢复进度展示
- 创建中禁止关闭页面或返回（需二次确认）

**用户场景：**
- **场景1 - 正常创建**：员工正常等待3步全部完成，看到成功提示
- **场景2 - 快速跳转**：步骤2完成后，员工急于配置飞书，点击步骤3直接跳转
- **场景3 - 页面意外关闭**：员工误关浏览器，重新打开后恢复进度
- **场景4 - 长时间等待**：某步骤执行时间较长，员工想了解详情

**异常情况：**
| 异常场景 | 现象 | 处理方式 |
|---------|------|---------|
| WebSocket断开 | 进度突然停止更新 | 自动降级为轮询，显示"连接已切换为轮询模式"提示 |
| 步骤执行超时 | 某步骤执行超过预期时间 | 显示"该步骤执行时间较长，请耐心等待"，提供"查看日志"按钮 |
| 总超时失败 | 10分钟仍未完成 | 显示失败页面，提供"重试"和"联系管理员"按钮，保留已完成的步骤状态 |
| 步骤失败 | 步骤图标变红显示失败 | 展开错误详情，显示具体错误信息和解决建议，提供"重试当前步骤" |
| 用户关闭页面 | 创建过程中用户关闭标签页 | 后台继续执行，下次进入时根据任务状态恢复进度或显示结果 |
| 浏览器崩溃 | 创建过程中浏览器崩溃 | 后台任务继续执行，重新登录后根据任务ID恢复进度展示 |
| 网络完全断开 | 用户设备断网 | 显示离线提示，网络恢复后自动重连并同步最新进度 |

---

### 3.4 创建完成弹窗

#### 功能规格

**触发条件：**
- 创建流程全部步骤成功完成
- WebSocket 接收到 "completed" 状态

**交互跳转说明：**
1. 显示成功弹窗，包含：成功图标、提示文案、操作按钮
2. 根据配置状态显示不同提示：
   - 已配置机器人："部署完成，正在等待管理员审批"
   - 跳过配置："部署完成，请稍后配置飞书机器人"
3. 提供两个按钮："打开 OpenClaw 项目"、"查看审批单"

**预期结果：**
- 弹窗突出显示成功状态
- 明确告知用户当前状态（审批中/待配置）
- 提供明确的下一步操作入口

**约束条件：**
- 弹窗必须手动关闭（不提供自动关闭）
- 点击"打开项目"跳转至项目配置管理页（新窗口）
- 点击"查看审批单"跳转至审批状态查看页
- 提供"稍后再说"按钮，返回首页

**用户场景：**
- **场景1 - 立即配置**：员工点击"打开 OpenClaw 项目"立即进入配置页开始配置
- **场景2 - 查看审批状态**：员工想了解审批进度，点击查看审批单了解当前审批队列
- **场景3 - 稍后处理**：员工当前较忙，点击"稍后再说"返回首页，稍后从项目卡片进入
- **场景4 - 分享给同事**：员工截图成功页面分享给团队成员

**异常情况：**
| 异常场景 | 现象 | 处理方式 |
|---------|------|---------|
| 跳转页面加载失败 | 点击按钮后新页面无法打开 | 显示"页面打开失败"提示，提供"重试"和"在新标签页打开"选项 |
| 审批单不存在 | 点击查看审批单但数据未生成 | 显示"审批单生成中，请稍后重试"，5秒后自动刷新 |
| 权限丢失 | 跳转后发现无权限访问 | 显示403错误页，引导联系管理员，记录安全日志 |
| 弹窗无法关闭 | 点击关闭按钮无响应 | 提供强制关闭入口（ESC键），记录错误日志 |
| 按钮重复点击 | 用户快速多次点击按钮 | 按钮添加防抖处理，首次点击后禁用，防止重复操作 |

## 第四章：项目配置管理页（Project Admin）

### 页面概述

OpenClaw 项目的核心管理页面，提供控制台、代码模式、终端三种视图。

**页面 URL：** `/projects/:id/admin`

---

### 4.1 顶部工具栏

#### 功能规格

**触发条件：**
- 用户从首页点击"配置 OpenClaw"
- 用户通过 URL 直接访问
- 其他页面点击项目相关链接

**交互跳转说明：**
1. 左侧：返回按钮（根据打开方式决定返回或关闭）
2. 中间：项目头像 + 名称 + 状态标签
3. 右侧：视图模式切换按钮组（控制台/代码/终端）
4. 最右侧：机器人信息下拉按钮

**预期结果：**
- 返回按钮根据 `window.opener` 判断：有新窗口则关闭，无则返回首页
- 状态标签实时反映项目运行状态
- 当前视图模式按钮高亮显示

**约束条件：**
- 项目信息需在 1s 内加载完成
- 状态标签每 30s 自动刷新
- 项目不存在时显示 404 错误页
- 无权限访问时显示 403 错误页

**用户场景：**
- **场景1 - 从新窗口打开**：员工从首页点击"配置 OpenClaw"，在新窗口打开配置页，点击返回直接关闭窗口

|---------|------|---------|
| 探测命令执行失败 | SSH/ping命令失败 | 记录失败原因，标记为"探测失败"状态，继续下一轮探测 |
| 告警通知失败 | 飞书消息发送失败 | 重试3次，仍失败则记录告警日志，不阻塞监控流程 |
| 监控自身异常 | 监控服务CPU过高或内存溢出 | 自动重启监控服务，保留监控数据，发送"监控服务异常"告警 |
| 误报频繁 | 实例实际正常但频繁告警 | 增加判定阈值，连续3次异常才触发告警，减少误报 |
| 静默期配置错误 | 设置了不合理的静默时间 | 验证静默期范围（最长24小时），超限提示"静默期过长" |
| 告警风暴 | 大量实例同时异常导致告警风暴 | 启用告警合并，5分钟内同类告警合并为一条消息 |

**约束条件：**
- 监控不占用过多资源（CPU < 5%）
- 告警去重（同一问题 1 小时内只发一次）
- 告警分级：警告/严重/致命
- 支持告警静默期设置

## 第十二章：通用功能规格

### 12.1 权限控制

#### 功能规格

**触发条件：**
- 用户访问任何页面/接口
- 用户执行任何操作

**交互跳转说明：**
1. 登录时获取用户角色和权限
2. 前端路由守卫校验页面权限
3. 后端接口校验操作权限
4. 无权限时返回 403 错误

**预期结果：**
- 权限控制覆盖所有页面和接口
- 权限变更实时生效（重新登录）
- 越权操作被拒绝并记录日志

**用户场景：**
- **场景1 - 员工权限控制**：普通员工只能查看自己的项目，无法查看他人项目或访问管理后台
- **场景2 - 管理员权限**：管理员可以查看所有项目并执行管理操作
- **场景3 - 权限变更**：员工调岗后，重新登录后自动获取新的权限配置
- **场景4 - 越权拦截**：用户尝试通过URL直接访问无权限页面，被系统拦截

**异常情况：**
| 异常场景 | 现象 | 处理方式 |
|---------|------|---------|
| 权限数据加载失败 | 登录后无法获取权限 | 使用默认最低权限（普通员工），允许访问首页，其他功能提示"权限加载失败" |
| 权限缓存过期 | 操作时被提示无权限 | 清除缓存重新获取权限，如仍无权限则返回403 |
| 角色权限配置错误 | 配置文件中权限语法错误 | 启动时校验配置文件，错误时拒绝启动并提示具体错误位置 |
| 接口未设置权限 | 后端接口未添加权限校验 | 代码审查检查，未设置权限的接口默认拒绝访问（白名单机制） |
| 权限提升漏洞 | 用户通过修改请求参数提升权限 | 后端严格校验权限，不信任前端传来的权限信息 |

**约束条件：**
- 支持 RBAC 模型
- 权限粒度：页面级 + 操作级
- 权限数据缓存时间：5 分钟
- 敏感操作需二次认证（预留）

### 12.2 错误处理

#### 功能规格

**触发条件：**
- 接口请求失败（4xx/5xx）
- 网络异常
- 业务逻辑错误

**交互跳转说明：**
1. 统一错误拦截处理
2. 显示友好的错误提示
3. 提供重试/返回/联系支持选项
4. 记录错误日志

**预期结果：**
- 用户能感知错误并知道如何处理
- 错误信息不暴露敏感信息
- 网络错误自动重试（3 次）

**用户场景：**
- **场景1 - 网络错误恢复**：用户网络短暂中断，系统自动重试请求，用户无感知
- **场景2 - 服务器错误提示**：遇到500错误，用户看到友好提示"系统繁忙"并提供重试按钮
- **场景3 - 权限错误处理**：用户尝试无权限操作，系统提示"您无权限执行此操作"并记录日志
- **场景4 - 业务错误处理**：用户输入非法参数，系统提示具体错误原因并引导修正

**异常情况：**
| 异常场景 | 现象 | 处理方式 |
|---------|------|---------|
| 错误重试耗尽 | 自动重试3次仍失败 | 显示"操作失败，请稍后重试"，提供"联系支持"入口 |
| 错误信息泄露 | 错误详情中包含敏感信息 | 统一错误包装，生产环境不暴露堆栈和内部错误详情 |
| 错误提示文案缺失 | 新类型错误无对应文案 | 兜底显示"操作失败"，记录日志提示开发补充文案 |
| 错误日志过大 | 错误详情超过日志大小限制 | 截断超长日志，保留关键信息（错误类型、用户、时间） |
| 频繁相同错误 | 同一用户频繁触发相同错误 | 速率限制，5分钟内相同错误只记录一次，避免日志刷屏 |
| 错误处理死循环 | 错误处理逻辑本身报错 | 设置最大处理深度，超过后强制返回通用错误响应 |

**约束条件：**
- 错误提示文案统一规范
- 500 错误显示"系统繁忙，请稍后重试"
- 错误日志包含：用户、时间、操作、错误详情
- 关键错误实时告警

### 12.3 日志审计

#### 功能规格

**触发条件：**
- 用户执行关键操作（创建、删除、配置变更等）
- 管理员执行管理操作

**交互跳转说明：**
1. 记录操作日志到数据库
2. 日志字段：用户、时间、IP、操作类型、操作对象、操作结果
3. 提供日志查询界面（管理员）
4. 支持日志导出

**预期结果：**
- 关键操作 100% 记录
- 日志不可篡改
- 查询响应时间 < 2s

**用户场景：**
- **场景1 - 操作追溯**：管理员发现配置异常，通过日志查询谁在什么时间修改了配置
- **场景2 - 安全审计**：安全团队定期检查日志，发现是否有越权操作或异常访问
- **场景3 - 问题排查**：项目被误删除，通过日志找到删除操作人和具体时间
- **场景4 - 合规报告**：生成季度操作日志报告，满足企业合规审计要求

**异常情况：**
| 异常场景 | 现象 | 处理方式 |
|---------|------|---------|
| 日志写入失败 | 数据库连接失败导致日志丢失 | 本地文件缓冲，恢复后批量写入，关键操作同步等待写入成功 |
| 日志查询超时 | 查询90天日志耗时过长 | 默认只查询最近7天，大范围查询需确认，提供导出异步查询 |
| 日志被篡改 | 发现日志记录被非法修改 | 数字签名校验，发现篡改立即告警并锁定日志功能 |
| 日志存储满 | 磁盘空间不足无法写入新日志 | 自动清理最旧的分区，保留关键安全日志，发送存储告警 |
| 单条日志超大 | 操作详情超过10KB | 截断超长内容，保留前10KB，记录"内容已截断"标识 |
| 归档失败 | 上传到对象存储失败 | 保留本地副本，重试3次，仍失败则标记为"待归档" |
| 日志格式异常 | 新代码写入的日志字段缺失 | 兼容处理缺失字段，显示为"-"，提示开发补充字段 |
| 日志导出超时 | 导出大量日志时超时 | 异步导出，提供下载链接，超时后提示"正在生成，请稍后下载" |

**约束条件：**
- 日志保留时间：90 天
- 单条日志大小限制：10KB
- 日志表分区存储
- 支持日志归档到对象存储
